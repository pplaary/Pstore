# PStore V4 规格书

> 版本：v4.0 | 日期：2026-06-20
> 技术栈：React Native 0.76 + Expo SDK 52 + TypeScript
> 定位：便利店商品管理与智能查价助手
> 核心：商品 CRUD → AI/语音/扫码查价加购 → 实时计价

---

## 变更历史

| 版本 | 日期 | 变更摘要 |
|------|------|---------|

## 一、设计理念

- **查价优先**：主要使用场景是快速查价，加购结账是次要场景
- **管理模式**：单身份设计，日常为普通模式（查价/加购/结账）；连击标题 5 次 → PIN 验证进入管理模式，可新增/编辑/删除商品及修改配置；主动退出回到普通模式
- **AI 可选**：AI 是增强输入通道，不是运行前提。无 AI 时降级为搜索+手动模式
- **离线可用**：商品数据全量存本地 SQLite，无网也能用
- **三层数据**：N1 家庭服务器（主存储+AI配置下发）→ 本地 SQLite（始终可用）→ WebDAV（手动兜底）
- **两种运行态**：连上 N1 时 AI 配置/WebDAV 由服务端托管（App 内隐藏）；单机运行时本地配置 AI 和 WebDAV

### 4.1 顶栏

- **左**：≡ 菜单，点击展开侧滑抽屉
- **中**：PStore 标题

  - 管理模式：显示「PStore [管理]」，再次连击标题 5 次 → 退出管理模式

### 4.2 聊天/搜索区域

**有 AI 时**：聊天模式。用户发文字/语音 → AI 解析意图 → 返回商品卡片。多匹配列候选，无匹配提示「未找到」。

**无 AI 时**：搜索模式。输入文字 → 本地 FTS5 实时搜索 → 直接展示匹配商品卡片列表。相当于搜索框，不区分 AI/用户气泡。

### 4.4 底部输入栏

- 左：🎤 语音按钮（有 AI 时可用，按住说话）
- 中：输入框，placeholder 随模式变：「说"可乐多少钱"」/ 「搜索商品名…」
- 右：📷 相机按钮（扫码+拍照）

## 五、数据模型

### 5.1 Product

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | UUID |
| name | TEXT | 商品名 |
| aliases | TEXT | 别名，逗号分隔 |
| pinyin | TEXT | 拼音首字母，自动生成 |
| price | REAL | 售价 |
| spec | TEXT | 规格（500ml / 200g 等） |
| imageUri | TEXT | 本地图片路径 |
| barcode | TEXT | 条码，唯一 |
| category | TEXT | 分类 |
| status | TEXT | IN_SHOP / OUT_OF_STOCK / TO_BE_PURCHASED |
| isDeleted | INTEGER | 0/1 软删除 |
| createdAt | TEXT | ISO 8601 |
| updatedAt | TEXT | ISO 8601 |

### 5.2 商品状态

| 值 | 含义 | 颜色 |
|----|------|------|
| IN_SHOP | 在售 | 蓝 |
| OUT_OF_STOCK | 缺货 | 灰 |
| TO_BE_PURCHASED | 待采 | 黄 |

### 5.3 分类（预设10种）

零食 / 饮料 / 粮油 / 调味 / 日化 / 生鲜 / 冻品 / 烟酒 / 日用 / 其他

### 5.4 软删除

isDeleted=true，禁止物理删除。新增同名+同规格商品时恢复条目而非新建。

### 5.5 重复检测

条码一致 → 直接判定重复。名称相似度 ≥ 90% + 售价/规格至少一项一致 → AI 辅助判定。命中后列表展示，管理模式中可选择合并或确认非重复。

## 六、AI 引擎（可选）

### 6.1 降级逻辑

```
App 启动
  ├─ 有 AI 配置且 API 可达 → 聊天模式（AI 驱动）
  └─ 无 AI 配置或 API 不可达 → 搜索模式（本地 FTS5 直搜）
```

切换无感知：同一个输入框，底层走不同路径，上层 UI 不区分。

### 6.2 AI 模式行为

**System Prompt 核心**：
```
你是 PStore 智能收银助手。
职责：理解自然语言（查价/数量/加购）。
做法：匹配商品库（名称/别名/拼音/模糊），输出结构化 JSON。
约束：不确定时列候选项；回复简洁≤3句；仅在售商品可加购。
```

**上下文注入**：购物车快照 + 当前模式（普通/管理）+ 最近 8-10 轮对话

**输出格式（Function Calling / JSON）**：
```json
{ "action": "addToCart"|"search"|"ambiguous"|"notFound",
  "productId": "...",
  "quantity": 1,
  "message": "已添加可乐 ×2",
  "confidence": 0.85 }
```

### 6.3 搜索模式行为

输入文字 → FTS5 匹配（名称/别名/拼音）→ 按权重排序（精确 > 别名 > 拼音 > 模糊；在售 > 缺货）→ 直接渲染商品卡片列表。

### 6.4 保护机制

- RAG Top K 20，不全量注入商品库
- productId 本地校验，不存在时拒绝加购
- AI 草稿卡 60 秒过期变灰，仍可点击确认
- 相同输入 5 分钟内复用缓存
- 中文数字预拦截（两瓶→2、半打→6）

## 七、相机

### 7.1 扫码

CameraX → 识别条码/EAN-13/QR → 匹配本地商品库：
- 唯一匹配 → 展示商品 + 加购按钮
- 无匹配 → 提示 + 可关联已有或新增商品
- 防抖：同条码值 2 秒内忽略

### 7.2 拍照识别

拍照 → 视觉模型 API → 返回商品列表（含置信度）→ 用户确认加购。无 AI 配置时隐藏拍照入口，仅保留扫码。

## 九、数据存储与同步

### 9.1 三层策略

| 层 | 条件 | 行为 |
|----|------|------|
| ① N1 云服务 | 配置地址且可达 | 自动拉取 AI 配置 + 全量同步商品；本地变更实时推送；WebDAV 隐藏 |
| ② 本地 SQLite | 始终运行 | 离线可用；收到 N1 数据后写入本地 |
| ③ WebDAV | 手动触发 | 单机运行时可用；导出商品库到 WebDAV / 从 WebDAV 恢复 |

### 9.2 N1 云服务 API

极简 REST，Docker 部署：

```
POST /api/config/get     → 返回 { apiUrl, apiKey, textModel, visionModel }
POST /api/config/set     → 设置 AI 配置（需 PIN 密码）
POST /api/products/sync  → 全量拉取商品列表
POST /api/products/push  → 推送本地变更（新增/编辑/删除）
```

### 9.3 切换状态

- 已连接 N1：绿色云图标 + 「已连接」
- N1 不可达：灰色云图标 + 「本地模式」
- WebDAV 模式：蓝色云图标

### 9.4 配置入口

顶栏 ☁️ 点击 → 配置中心：
- **N1 服务地址**（输入框，含端口）
- **WebDAV 配置**（URL / 账号 / 密码 / 测试连接 / 导出 / 恢复）
  - 仅单机运行时显示（N1 在线时隐藏，商品同步走 N1）
- **AI 配置**（API 地址 / Key / 文本模型 / 视觉模型）
  - N1 在线时从服务端拉取，灰显不可编辑，不显示在配置中心
  - 单机运行时手动编辑

## 十、权限（管理模式）

### 10.1 模式总览

单身份设计，不区分店员/老板。日常为**普通模式**，敏感操作需进入**管理模式**。

| 模式 | 可用操作 |
|------|---------|
| 普通模式 | 查价/搜索、加购/结账、扫码/拍照、语音（有 AI 时）、深色/关怀切换、查看 N1 同步状态 |
| 管理模式 | 普通模式全部 + 新增商品、编辑商品、软删除商品、清空商品库、N1 服务地址修改、AI 配置编辑（单机）、WebDAV 配置（单机）、商品数据导出 |

### 10.2 进入/退出

- **进入**：连击标题「PStore」5 次 → PIN 密码弹窗 → 验证通过进入管理模式
- **退出**：管理模式中再次连击标题「PStore [管理]」5 次 → 立即退出，回到普通模式
- PIN 无时效限制，管理模式状态下持续有效，直到主动退出或 App 重启
- App 重启后自动回到普通模式

### 10.3 PIN 密码

- 初次使用 / 未设置时：连击标题自动跳转 PIN 设置页（输入 + 确认）
- 已设置：弹窗输入 PIN，错误提示重试
- PIN 哈希存储，不可找回

### 10.4 UI 差异

| 元素 | 普通模式 | 管理模式 |
|------|---------|---------|
| 标题 | PStore | PStore [管理] |
| 侧滑抽屉 | 无商品管理/导出入口 | 显示全部入口 |
| 商品列表 FAB (+) | 隐藏 | 显示 |
| 商品长按菜单 | 无编辑/删除 | 有编辑/改状态/删除 |
| 配置中心 | 仅 N1 地址（读） | N1 地址可编辑 + AI 配置（单机）+ WebDAV（单机） |

## 十一、商品管理

### 11.1 商品列表

筛选：全部 / 在售 / 缺货 / 待采 + 分类下拉 + 排序（名称/价格/时间）
列表：缩略图 + 名称 + 规格 + 售价 + 状态标签
右下角 FAB 新增
长按弹出菜单（编辑/改状态/删除）

### 11.2 商品详情/编辑

字段：图片(点击更换) / 名称(必填) / 规格 / 售价 / 分类(下拉) / 状态(三段切换) / 条码(扫码或手动) / 别名(标签+增删)
价格历史变化曲线（折线图，数据来源于价格变更记录，无记录时隐藏）
返回时自动保存

### 11.3 批量管理

工具栏切换批量模式，每行 CheckBox，批量改价/改状态/软删除。

### 11.4 重复检测与合并

条码一致或名称相似度 ≥ 90% 判定疑似重复。左右并排 A/B 卡片 + [确认非重复] [合并]。合并时逐字段选择保留值，被合并商品名写入别名后软删除。

### 11.5 拼音首字母

保存商品时自动计算拼音首字母（可乐→kl），存入 pinyin 字段参与 FTS5 搜索。

## 十三、运维

- **性能指标**：冷启动 < 2s、搜索响应 < 300ms
- **网络质量指示**：顶栏状态区显示网络类型 + AI 延迟色标（绿 < 1s / 黄 1-3s / 红 > 3s）
- **数据导出标准化**：CSV UTF-8 with BOM、日期 ISO 8601

---

## 十四、凭证与安全

- 所有远程凭据（AI Key、WebDAV 密码）加密存储
- PIN 密码哈希存储
- 本地数据库文件加密（防止 root 后直接读取）
- 无网络传输加密层（依赖 N1 内网环境）

---

## 十五、无障碍

- 所有交互元素 contentDescription
- 商品卡片读取格式：「{名称} {规格}，{售价}，{状态}」
- 关怀模式：字体/间距/触控尺寸放大
- 暗色模式：开关 + 跟随系统选项
